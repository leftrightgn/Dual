================================================================================
                    DUAL - 操作方法 ＆ ゲームプレイガイド
                  (Controls & Gameplay Guide - Japanese)
================================================================================

本作『DUAL』は、強大なボスとの白熱した剣戟アクション、および魂の離脱と
新たな肉体への憑依（Possession）を特徴とする三人称3Dアクションゲームです。

肉体が力尽きてもゲームオーバーではありません。霊体（ゴースト）となって
フィールドを巡り、眠れる「新たな器（Vessel）」に乗り移ってボスを討伐せよ！

--------------------------------------------------------------------------------
【1. 基本操作方法 (Game Controls)】
--------------------------------------------------------------------------------

[ 移動・視点操作 ]
  W / A / S / D         : 前後左右へのキャラクター移動
  マウス移動            : カメラ視点の回転・見回し（三人称スプリングカメラ）
  マウス中クリック      : ロックオン（ボスを常に画面中心に捉える）
  F キー                : ジャンプ

[ アクション・戦闘 ]
  マウス左クリック      : 通常攻撃（連続クリックで3段コンボ：Slash1 → 2 → 3）
  マウス右クリック      : 盾ガード（長押しで構え維持、スタミナを消費して防御）
  スペースキー (Space)  : 回避ローリング（無敵時間あり、敵の攻撃をかわす）
  ガード直後の左クリック: ガードカウンター（敵の攻撃を防いだ／弾いた直後に強力な反撃）

[ 特殊システム：憑依 (Possession) ]
  Q キー                : 器（Vessel）への憑依
                          ※ HPが0になり霊体（ゴースト）になった状態で、
                             フィールドにある休眠中の器に近づいて [Q] を押す

[ システム ]
  ESC キー              : タイトル画面へ戻る


--------------------------------------------------------------------------------
【2. ゲームプレイと戦闘システム (Combat Mechanics)】
--------------------------------------------------------------------------------

◆ 3段階コンボ攻撃 (Combo Attacks)
  マウス左クリックをテンポよく入力することで、3連続の斬撃を繰り出せます。
  最後の3撃目はフィニッシャーとなり、大ダメージとともに敵をひるませます。

◆ ガード＆スタミナ管理 (Guard & Stamina System)
  マウス右クリックを押し続けると盾を構えて防御姿勢を取ります。
  攻撃を防ぐとスタミナを消費し、受けるダメージを約85%カットします。
  スタミナがゼロになると「ガードブレイク（体勢崩れ）」となり、
  一定時間無防備になるため、常にスタミナ残量に注意してください。
  ※ スタミナは攻撃やガードを行っていないときに自然回復します。

◆ ジャストガード・弾き (Just Guard / Deflect / Parry)
  ボスの攻撃が当たる直前（約0.2秒以内）の絶妙なタイミングで右クリックを
  押すと、「ジャストガード（弾き）」が発動します！
  ・スタミナを消費せず、逆にスタミナが即時回復
  ・ダメージを100%カット
  ・ボスの攻撃を受け止め、大きな隙を生じさせる

◆ ガードカウンター (Guard Counter)
  ガードまたはジャストガードの成功直後にマウス左クリックを押すと、
  素早い反撃技「ガードカウンター」が炸裂します。
  ボスに大きな態勢ダメージを与えてダウンを狙えます。

◆ 回避ローリング (Dodge Roll)
  スペースキーで任意の方向へ転がって回避します。
  ローリング中には無敵時間があるため、ボスの大技や広範囲の衝撃波
  （ショックウェーブ）をすり抜けるのに極めて有効です。


--------------------------------------------------------------------------------
【3. 器と憑依システム - 死を越えて戦え！ (Vessel & Possession System)】
--------------------------------------------------------------------------------

★ 本作最大のコアメカニクスです。

1. 肉体の死（ゴースト化）：
   ボスの猛攻を受けてプレイヤーのHPがゼロになると、肉体は崩壊しますが、
   魂は「霊体（Ghost）」となって戦場に留まります。
   ゴースト状態では空中を自由に浮遊し、高速で移動することができます。

2. 新たな器（Vessel）の探索：
   闘技場のどこかに、魂が入っていない休眠状態の「騎士の器（Vessel）」が
   静かに佇んでいます。
   ゴースト状態でフィールドを見渡し、その器を探してください。

3. 憑依（Possess）と戦線復帰：
   休眠中の器に近づくと、画面上に
       『 [Q] POSSESS VESSEL 』
   というエメラルドグリーンのメッセージが表示されます。
   ここで [Q] キーを押すと、魂が器に乗り移り、完全回復したHPと剣を携えて
   即座に戦線へ復帰することができます！

4. ボス討伐 (Defeat the Boss)：
   復活した新たな肉体で再び剣を抜き、ボスの残りの体力を削り切って
   見事ボスを討伐しましょう！


--------------------------------------------------------------------------------
【4. 画面の見方・ゲージ解説 (UI & HUD)】
--------------------------------------------------------------------------------

・画面左下ゲージ：
  [HPゲージ (赤)]     : 現在の体力。0になるとゴースト化します。
  [Staminaゲージ (緑)]: 回避やガードに消費するスタミナ。
  [Blockゲージ (青)]  : ガード耐久値。

・画面上部：
  [Boss HPゲージ]     : ボスの体力ゲージ。削り切ることで勝利となります。


--------------------------------------------------------------------------------
【5. 攻略のヒント (Tips for Victory)】
--------------------------------------------------------------------------------

1. ボスの大振りなジャンプ攻撃や衝撃波は、ガードするよりもスペースキーの
   回避ローリングでタイミングよく飛び込むのが安全です。
2. ガードを構えっぱなしにするとスタミナの回復速度が大幅に低下します。
   ボスの攻撃の合間には右クリックを離し、スタミナを急速回復させましょう。
3. 最初の肉体で倒されてしまっても、冷静にゴーストで器を探しましょう。
   器の位置を事前に把握しておくと、素早く憑依して戦闘を有利に進められます！
